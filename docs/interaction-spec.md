# 상호작용 명세

화면에 표시되는 컨트롤의 동작과 구현 우선순위를 관리한다. 클릭할 수 있는 모양의 요소는 반드시
동작하거나, 비활성 상태와 이유를 명확하게 보여줘야 한다.

## 상태 기준

- **연결됨**: 현재 목 데이터만으로 완결된 동작 또는 화면 이동이 가능하다.
- **목업 필요**: 서버 없이 모달·폼·로컬 상태로 먼저 완성할 수 있다.
- **API 필요**: 인증, 영속 저장, 파일 또는 외부 서비스 연결이 있어야 완성된다.

| 설정                             | API 필요  | Workspace 및 개인 설정 화면      | P2       |
| 도움말                           | 목업 필요 | 도움말 패널 또는 문서 화면       | P2       |

## 구현 순서

1. P0: 모든 이동 링크와 현재 동작의 피드백을 보장한다.
2. P1: 추천 등록, 곡 편집, Decision, 의견, 합주 기록을 로컬 목업 폼으로 연결한다.
3. P2: 파일 업로드, 공유, 알림, 설정을 API와 연결한다.
4. 각 컨트롤에 로딩, 성공, 실패, 빈 상태와 권한별 비활성 사유를 추가한다.

## 개인 작업실 동작

| 화면         | 핵심 컨트롤                          | 기대 동작                                    |
| ------------ | ------------------------------------ | -------------------------------------------- |
| 내 악기 추출 | 녹음·업로드, Target 교정, 분리 설정  | 근접 녹음에서 선택한 우세 악기 Track 생성    |
| 추출 결과    | 원본·추출본·제거음 A/B, 재처리       | 누음과 음색 손실을 비교하고 설정별 결과 유지 |
| 악보 편집    | 입력 도구, Inspector, Revision, 재생 | 구조화 악보를 편집하고 기준 음원과 동기 재생 |

## 완료 기준

- `Pressable`과 `Button`에 동작 또는 명시적인 `disabled` 상태가 있다.
- 저장형 동작은 성공 여부를 화면에서 확인할 수 있다.
- 동일 기능이 웹과 모바일에서 같은 결과를 만든다.
- URL 이동 후 새로고침해도 같은 화면이 복원된다.
- Owner 전용 동작은 Member에게 비활성 사유를 보여준다.
